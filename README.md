# Острова Эволюции

Игра-кликер про остров: игрок собирает энергию с древнего дерева, покупает
улучшения, вылупляет существ из яиц, соединяет их в лаборатории слияний и
застраивает остров жилищами под разные стихии.

Проект подготовлен к публикации на [Яндекс Играх](https://yandex.ru/games/):
подключён SDK платформы, есть облачные сохранения, пауза на рекламе и
мобильное управление.

## Стек

React 19 + TypeScript + Vite, Zustand (состояние), Phaser 4 (сцена острова),
IndexedDB (локальные сохранения) + облако Яндекс Игр.

## Команды

| Команда | Что делает |
|---|---|
| `npm run dev` | Дев-сервер на `http://localhost:5173` (с моком SDK) |
| `npm test` | Все тесты (unit + интеграционные, без браузера) |
| `npm run lint` | ESLint |
| `npm run typecheck` | Проверка типов |
| `npm run build` | Production-сборка в `dist` |
| `npm run preview` | Просмотр собранной игры на `http://localhost:4173` |
| `npm run release:yandex` | Сборка + архив для публикации в `release/` |

## Локальный запуск

```bash
npm install
npm run dev
```

В дев-режиме вместо настоящего SDK отдаётся его мок (`/sdk.js` подменяется
плагином Vite), поэтому игра запускается без платформы. Мок отвечает на те же
методы, что и настоящий SDK: можно проверять облачные сохранения, рекламу и
события платформы.

Проверить с настоящим SDK (нужен доступ к `sdk.games.s3.yandex.net`):

```bash
npm run dev
YANDEX_SDK_REAL=1 npx @yandex-games/sdk-dev-proxy -h http://localhost:5173 --dev-mode=true
```

Отладочные команды в консоли (только дев-сборка):

```js
window.__adsDebug.state()           // статистика показов и пейсинг
window.__adsDebug.canShowInterstitial()
window.__adsDebug.showInterstitial() // показать полноэкранную рекламу (мок)
window.__adsDebug.disable()         // выключить рекламу на время отладки
window.__errorsDebug.list()         // последние перехваченные ошибки
```

Чтобы не ждать пейсинг при проверке точек показа, откройте игру с `?adsFast=1`
(только dev): задержка первого показа, кулдаун и минимум действий уменьшаются,
и мок-реклама появляется уже после нескольких действий.

## Реклама

Полноэкранная реклама вызывается только из точек показа — после законченного
действия игрока, никогда по клику, на старте или по таймеру:

| Точка | Когда срабатывает |
|---|---|
| `egg-hatched` | открылось яйцо и появилось существо |
| `fusion-done` | слияние завершилось новым существом |
| `upgrade-bought` | куплено улучшение (клик или солнечный источник) |
| `habitat-upgraded` | жилище построено или повышено в уровне |
| `screen-change` | игрок перешёл на другой экран |

Показ ограничен пейсингом: не раньше 2 минут от старта, не чаще раза в 3 минуты
и не раньше 25 действий игрока. Игра и звук останавливаются на время показа и
возобновляются после него; если колбэки SDK не пришли, страховочный таймаут
вернёт управление. Вознаграждаемой рекламы в интерфейсе нет — по решению
команды (механик за награду не заявлено).

Выключить рекламу целиком — одна строка в `src/platform/bootstrap.ts`:
`configureAds({ enabled: false })`. Игровая логика при этом не меняется.

## Публикация на Яндекс Играх

```bash
npm run release:yandex
```

Команда собирает игру и складывает архив `release/evolution-isles.zip`. Скрипт
упаковки сам проверяет требования платформы:

- `index.html` лежит в корне архива (п. 1.22);
- в архив не попадают исходники, source map, кэши и зависимости разработки;
- размер в распакованном виде укладывается в 100 МБ (п. 1.21).

Что указать в черновике игры:

- **Архив** — `release/evolution-isles.zip`;
- **Облачные сохранения** — включить (игра их использует, п. 1.11);
- **Монетизация** — включена: полноэкранная реклама показывается только в
  логических паузах (см. `src/platform/adPoints.ts`);
- **Поддерживаемые платформы** — десктоп и мобильные (телевизоры не заявлены);
- **Ориентация** — любая: вёрстка работает и в портретной, и в альбомной.

## Звук

Звуки **синтезируются кодом** (`src/platform/sounds.ts`) и не занимают места в
архиве: нет файлов, нет внешних загрузок, нет вопросов с лицензиями. Звук
работает сразу после сборки и при плохой связи.

| Звук | Когда играет |
|---|---|
| `click` | клик по дереву (с легкой вариацией тона, чтобы не «пулемётило») |
| `upgrade` | куплено улучшение — корни силы или солнечный источник |
| `egg` | из яйца вылупилось существо |
| `fusion` | слияние дало новое существо |
| `mutation` | выпала мутация |
| `habitat` | жилище построено или улучшено |
| `achievement` | получено достижение |
| `ui` | переход между экранами |

Правила платформы выполняются автоматически: звук останавливается при потере
фокуса и сворачивании вкладки (п. 1.3), на время рекламы (п. 4.7) и после
выключения игроком (п. 6.2). Кнопка 🔊 в верхней панели включает и выключает
звук, настройка запоминается между сессиями.

Банк звуков собирается при первом действии игрока: до него браузеры всё равно
не разрешают воспроизведение.

## Экономика

Все числа прогрессии живут в одном модуле — `src/game/balance.ts`, и там же
объяснено, почему выбраны именно такие формулы. Коротко о правилах:

- **Улучшения клика и солнечного источника** дорожают с каждой покупкой
  (×1,7 и ×1,75), поэтому «вечного» дешёвого источника силы нет;
- **яйцо** дорожает с каждым вылуплением (×1,16, после 40 яиц рост слабее) —
  коллекция требует усилий, но не упирается в стену: цена никогда не превышает
  30 минут текущего дохода острова;
- **жилища и слияния** — milestones с фиксированными растущими ценами;
- **офлайн-доход** начисляется максимум за 4 часа отсутствия.

Цены — производные от прогресса: они пересчитываются из состояния и при
загрузке сохранения, а не берутся из файла. Подделанное сохранение не даёт
дешёвых покупок, а смена баланса сразу применяется к текущему прогрессу.
Схема сохранения — версия 4 (старые версии мигрируют без потери прогресса:
уровень улучшений восстанавливается из прежней цены).

Кривая прогрессии проверяется симуляцией в `tests/game/economy.test.ts`;
подробности и таблица «было → стало» — в [`docs/economy-balance.md`](docs/economy-balance.md).

## Что внутри

| Каталог | Содержание |
|---|---|
| `src/game` | Игровая логика: экономика, существа, слияния, жилища, сохранения |
| `src/platform` | Слой платформы: SDK, облако, реклама, звук и синтез звуков, пауза, ошибки |
| `src/ui` | Небольшие экранные компоненты (загрузка, облачная панель) |
| `tests` | Тесты игровой логики и платформенного слоя |
| `scripts` | Упаковка архива, восстановление окружения |
| `docs` | План работ по этапам и описание механик |

Подробности: [`docs/yandex-games-plan.md`](docs/yandex-games-plan.md) — этапы
подготовки к платформе, [`docs/gameplay-fusion-habitats.md`](docs/gameplay-fusion-habitats.md) —
слияния, мутации и жилища, [`docs/economy-balance.md`](docs/economy-balance.md) —
баланс экономики и кривая прогрессии.

## Известные ограничения

- **Вознаграждаемой рекламы в интерфейсе нет**: показывается только
  полноэкранная реклама в паузах.
- **Промо-ссылки** (`environment.referrer` из SDK) пока не обрабатываются.
