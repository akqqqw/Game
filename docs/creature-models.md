# 3D-модели существ: как устроено и что нужно от Blender

В карточке существа (коллекция → любое открытое существо) показывается
вращающаяся 3D-модель. Пока своих моделей нет, каждое существо рисуется
**процедурно** — из примитивов, по стихии и редкости. Это не заглушка «на
скорую руку»: силуэт, палитра, украшения и свечение у каждого существа свои и
не меняются между открытиями. Готовые модели из Blender просто занимают место
процедурных, по одной, когда вы их сделаете.

## Как игра выбирает модель

1. Есть ли существо в списке `creatureModelFiles` (`src/game/creatureModels.ts`)
   и лежит ли файл `public/models/creatures/<id>.glb` — показываем файл.
2. Файла нет, он не догрузился или повреждён — процедурная модель по рецепту.
3. WebGL в браузере нет — остаётся эмодзи (карточка не ломается).

Модель нормализуется автоматически: игра центрирует её по bounding box и
приводит к единому размеру, поэтому масштаб в Blender не важен. Ориентацию
тоже можно не настраивать: glTF-экспорт из Blender разворачивает персонажа
лицом к камере, а камера витрины стоит на оси +Z.

## Что нужно от модели

| Параметр | Требование | Почему |
|---|---|---|
| Имя файла | `<id>.glb`, id — из `src/game/creatures.ts` (например `mossling.glb`) | игра ищет модель по имени существа |
| Формат | glTF 2.0, **binary (.glb)**, один файл | один файл = проще архив и загрузка |
| Драко-сжатие | **выключено** | декодер Draco не входит в сборку; скажите, если он нужен — добавлю |
| Масштаб | любой | нормализуется при загрузке |
| Ориентация | вперёд = −Y в Blender (стандарт glTF) | так модель смотрит в камеру |
| Полигонаж | до ~4 000 треугольников на существо | мобильные устройства и размер архива |
| Материалы | Principled BSDF: Base Color + Roughness 0.5–0.8, Metalness 0–0.2 | подходит к мягкому свету витрины |
| Свечение | Emission того же оттенка, что Base Color, Strength 0.2–0.6 | свечение у редких и мифических выглядит уместно |
| Текстуры | одна на существо, до 512×512, PNG/JPG внутри `.glb` | 512×512 хватает для силуэта, весит мало |
| Анимация | не нужна | игру дополняет сама витрина: вращение, покачивание, блик |
| Скелет | не нужен | статичная модель — самый лёгкий путь |

Если хочется единого «плоского» стиля (как у палитры острова), достаточно
плоских Base Color без фототекстур — витрина добавит свет и тень.

## Как добавить модель в игру

1. Положите файл в `public/models/creatures/<id>.glb`.
2. Допишите id в список `creatureModelFiles` в `src/game/creatureModels.ts`:

   ```ts
   export const creatureModelFiles: readonly string[] = ['mossling', 'dewfin']
   ```

3. Перезапустите дев-сервер (или пересоберите архив): модель появится в карточке.

Список нужен, чтобы игра не дёргала сеть и не получала 404 для существ, чьи
модели ещё не готовы. Если предпочитаете иначе — можно проверять файлы
автоматически, скажите.

## Почему three.js, а не Phaser 4

Phaser 4 не умеет 3D. Плоскостная сцена острова остаётся на Phaser, а модели
показывает отдельный слой на three.js. Модуль витрины грузится **лениво**
(≈157 КБ в сжатом виде) — только когда игрок открыл карточку существа, поэтому
старт игры и архив не потяжелели.
